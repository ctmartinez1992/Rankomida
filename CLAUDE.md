# Project Preferences

## Workflow

Always follow the full OpenSpec flow for any change to this project:

1. **Propose** — create a change with `openspec-propose` (or `openspec-explore` first if the idea needs thinking through), producing `proposal.md`, `design.md`, `specs/`, and `tasks.md`
2. **Apply** — implement the tasks with `openspec-apply-change`
3. **Archive** — sync specs and archive the change with `openspec-archive-change`

Never implement changes directly without going through this flow.
